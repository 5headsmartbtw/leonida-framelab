# Security and distribution

The default build is CPU-only. GPU experiments use local application-scoped dependencies; this project does not modify drivers, system DLLs or Windows protection settings. Do not commit proprietary kernel dumps, SDK distributions, game payloads or secrets.

Report ordinary correctness/compatibility problems as issues. For a suspected security issue, use GitHub private vulnerability reporting when available, or contact the maintainer without posting exploit details, credentials or third-party data publicly.
